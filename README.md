# PinPro Marketplace

Marketplace de servicios locales en tiempo real de alto tráfico. Plataforma diseñada para la conexión inmediata entre clientes y profesionales locales mediante geolocalización y notificaciones en tiempo real, con foco en rendimiento (arquitectura de alto tráfico) y seguridad (Zero-Trust).

## Instrucciones para Sincronización con GitHub

Esta plataforma está integrada con el servicio de despliegue de AI Studio. Para sincronizar tu proyecto con GitHub:

1. **Repositorio:** Asegúrate de tener un repositorio nuevo (o vacío) en GitHub.
2. **AI Studio:** En la interfaz de AI Studio, busca el menú de configuración o el botón de "Sync to GitHub" (como se ve en la captura de pantalla que compartiste).
3. **Autenticación:** Sigue las instrucciones del navegador para autorizar la conexión entre AI Studio y tu cuenta de GitHub.
4. **Rama:** Selecciona la rama principal (usualmente `main`).

El sistema de AI Studio se encargará de realizar el `commit` inicial y programar los despliegues automáticos desde la plataforma.
